# ModernVulkan
A simple Vulkan project demonstrating how to use modern Vulkan 1.3 and newer features, including dynamic rendering without traditional render passes.

Most Vulkan tutorials available online still rely on deprecated APIs and outdated practices that are no longer recommended for modern Vulkan development. If you're looking for a modern Vulkan tutorial for 2026/2027, this is the place to start.

This is not a complete Vulkan guide, but it provides a solid foundation for learning modern Vulkan without deprecated code, unnecessary boilerplate, or outdated patterns.
